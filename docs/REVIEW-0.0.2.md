## Standards

未发现文档编码规范的硬性违反；自动工具规则另外运行。

- 高优先级正确性：所有 RpcError 继承 Rejected 会把可能已执行的请求记为确定拒绝。已修复为保守 UNKNOWN；补充 5 类状态码回归。
- 中优先级正确性：不兼容或预检失败的 staging 残留导致下次升级失败。已修复清理范围，包含兼容元数据抛异常；补充重复尝试回归。
- 判断性建议：维护/升级模块直接读取部分账本表，存在可能的 Feature Envy/Shotgun Surgery；权限/问题处理存在可能的 Repeated Switches。暂留为维护建议，没有为它们引入通用插件层。

复查还收紧了卸载对服务路径的归属核验，避免移除另一安装的同名服务。

## Spec

- 首次 setup 原来没有公开的验收结果写入路径。新增 `acceptance verify`，核对原生输入、已送达卡片和 Lark GET 消息；桌面来源/工具效果需要明确本机确认。
- schema 1 被发行包的 schema 2 运行范围拒绝。分离可接受迁移输入与运行 schema；先复制备份并由候选程序实际迁移/检查，源库保持不变。
- 前台心跳曾可冒充服务交接。新增已启用 systemd 服务 MainPID、实时心跳和明确配置路径的对应检查。
- 复查发现空闲 Stop 也可能误过控制验收。新增 Allow 应用时间与其后 Stop 的忙碌/空闲观测，旧/无证据记录不能新通过此项。

未发现超出当前 MVP 的功能范围扩张。完整产品尚未验收部分集中列于发布报告，不用本地测试代替真人、OS 或公开发行门禁。

总计：Standards 2 项正确性问题已修、2 项判断性维护建议保留；Spec 4 项正确性/覆盖问题已修。两个轴当前均无未处理的已复现阻断问题。
