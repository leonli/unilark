# Unilark 0.0.6 · 群聊回归对话

2026-09-13，实验版。此前每轮的输入回执、中间助手回复和状态卡挤满群聊。
本版把过程收敛到一张动态消息，最终正文单独发到聊天底部，便于阅读和继续对话。

## 实际交互

| 阶段 | 群聊表现 |
|---|---|
| 收到输入 | 一张紧凑的等待/思考卡，不另发“已保存”或 ACCEPTED |
| 思考、查找、写文件 | 原卡更新自然语言状态，不逐步发送过程或空回复 |
| 执行命令 | 原卡显示脱敏命令摘要，最多 180 字；不发送工具输出流水 |
| 忙时继续发话 | 原卡显示后续排队数量；普通输入仍排队，`/steer` 补充当前轮 |
| 需要决定 | 保留独立审批/问答卡，原状态卡显示等待确认 |
| 收到正式答复 | 进度卡变为“本轮结束”并移除按钮；正文作为新消息发出 |
| 正文与图表 | 无“AGY 回复”标题/项目页脚；Markdown、Mermaid 图片保留，长结果才分条 |
| 停止、失败、断线 | 原卡显示实际状态；缺少最终答复时不把之前的计划当作成果 |

每轮通常是一条持续更新的过程消息和一条最终答复；审批/问答和长结果按需要增加。
旧私聊兼容模式沿用原投影。群里管理入口仍由 `/status` 等命令显式打开。
Markdown 本文可直接阅读；自动收集和上传本机文件附件尚未实现。

## 验证

144 本地用例完整通过；真实 Lark 无标题群卡 1 项、真实 AGY 群模式 1 项通过。
Ruff、格式、mypy 55 源文件和 pip check 通过。未复跑既有浏览器/其他原生控制套件。

测试映射见 [E2E 对照](E2E-COVERAGE.md)。新增本地旅程覆盖消息数量、命令脱敏、队列、重启、
长结果、停止、旧按钮、审批/问答、失败结果和旧历史迁移。只投影公开答复和命令字段，排除 thinking 与签名。
真实 Lark 验证无标题状态卡、Markdown/Mermaid 卡发送、同一消息更新及群归属，测试卡随后撤回。
真实 AGY 验证群目标最终答复与重启去重，投递端为本地 Recorder；不将其称作真人手机 E2E。

手机明暗模式、消息提醒及实际触控仍需真实客户端观察；API 返回成功不代替视觉验收。

## 升级

沿用 schema 3；无需新增 Lark 权限、发布菜单或重新配对。
空闲升级时从旧群已观测历史之后开始新投影，原绑定、历史及已知消息 ID 保留。
程序仍遵守成员核验、固定群路由、审批指纹和未知结果不重发。执行并发仍为 1。
