# 安全模型

对应 PRD 10.7、12.3、8.8。本文件在 Spike 期间随实测修订。

## 实验版边界（PRD 8.8）

- **认证归 Unilark**：Lark 侧白名单，谁能点审批/停止。
- **授权归 AGY**：工具能否执行由 AGY 自身审批弹窗决定，Unilark 只把弹窗镜像到
  Lark 并限定谁能点。依赖执行前钩子的条目标「待官方 API」。

## Spike 实测的本地接口（2026-09-12，已并入 PRD 10.7）

AGY 2.13.0 桌面端把自己的 UI 跑在 `https://127.0.0.1:<随机高端口>` 上，
UI 与本地 `language_server` 之间走 gRPC-web。该 RPC 面的唯一凭据是
`x-codeium-csrf-token`，其值明文写在该端口首页 HTML 的 `window.__APP_CONFIG__` 里。

**结论：本机任意能发起 loopback HTTP 请求的进程都能读到该 token 并驱动这个
RPC 面。** 这意味着 PRD 8.8「优先 `--remote-debugging-pipe`（不开端口）」所规避的
那一类风险，在 AGY 自身的架构里本来就存在，与 Unilark 是否开调试端口无关。

产品行为要求：
- 安装向导不得宣称「不开调试端口 = 本机其他进程无法驱动 IDE」。
- FR-SC-10 的措辞需要按上述事实重写。
- AGY 自有接口与 Unilark 辅助控制面分别记录，不将其中一项的限制推广成整体安全保证。

续跑修正：旧 Spike 自己还把 CDP 管道转成了 9800 无认证 HTTP 控制面，因此不能笼统
宣称 Unilark 没有新增暴露。该端口已关闭，改用 0600 Unix socket，父目录 0700。
AGY 自有 API 的风险仍存在；本次 VM 的 `/proc` 未启用 hidepid，其他本地用户可读取
language_server 命令行中的认证资料。没有自动修改系统挂载策略。

新客户端只选择配置指定的进程树；token 不出现在 Endpoint repr、CLI discover 或
错误消息中。登录态与证据保留在仓库外。

## 0.0.5 独立会话群

owner 身份仍保留原配对 DM，消息实际 chat 单独持久化。app、tenant、owner 用户及原消息 ID 都需匹配。
未知群不执行输入或控制；群内 quote/action 不能重定向另一会话。输入事件、派生 UI 请求和卡片目的地跨重启保存。

群由机器人拥有，仅邀请已配对用户；机器人锁定邀请和资料编辑、禁止群分享。
核验群类型、标记、机器人/用户数量及完整人类成员 ID。核验失败暂停群输入输出，在控制 DM 提示。
成功核验缓存 5 秒，失败冷却 15 秒；图片生成后再次核验。Lark API 没有“核验成员并原子发送”保证，不能声称零竞争窗口。

建群前验证租户权限。建群意图先落盘，返回不确定时仅按唯一标记查找，不凭创建 UUID 永久去重。
新入口等待原生会话空闲，保存历史基线，不转发既有私聊历史；旧消息目的地不变。
普通工具过程不逐条发卡，审批和问题保留。群暂停不阻断其他会话/控制 DM 的投递，也不延长自动拒绝/取消的过期策略。

schema 3 防止旧版绕过群检查更新已知消息 ID。不要把旧版 manifest 的兼容范围扩成 3。
本地账本含待发首条任务，按现有 0700/0600 保护。原生执行仍串行，不新增多人共享授权。

## 0.0.2 网关保护

- owner/account/tenant/user/chat 严格绑定，旧卡片还核对 message ID、binding 和原请求指纹。
- 权限/问题 token 一次性使用、5 分钟过期；过期只提交拒绝或取消，不自动授权。
- 输入和卡片状态跨重启持久化。RPC 错误、丢失回执、新卡片发送未知均保守处理，不能当作未执行。
- UNKNOWN 本机裁决产生 DISMISSED 和审计，保留暂停；不会重发或删除历史记录。
- 已知 App Secret 的输入拒绝保存；投影、CLI history 和日志使用脱敏，SDK 原始载荷不写日志。
- 诊断与审计导出不包含消息正文、凭据和原始 thinking；账本中的任务正文仍是敏感用户数据。
- 数据目录 0700、数据库/凭据/轮转日志 0600；凭据作为数据读取，不执行 shell。
- 独立版本环境、包文件哈希、迁移前一致性备份；回退不覆盖升级后接收的数据。

脱敏并不是所有未知 Secret 的自动识别保证；用户仍需避免把不应离开主机的信息发送到 Lark。
AGY 的工具权限、外部登录与本机回环接口边界保持上文说明；没有独立工具沙箱保证。

2026-09-12 本地审查：运行依赖 pip-audit 无已知漏洞；gitleaks 扫描本地 Git 历史与源码快照未发现密钥。
发行包另核对当前 App Secret 不在文件或 wheel 内容中。未公开发行，不声称通过外部安全认证。
