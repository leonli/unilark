# M1 实现与验证记录

日期：2026-09-12。状态：**本机真实端到端最小闭环通过；未公开发行。**

真实 Lark 已完成应用配置、本人配对和普通收发，用户确认可工作。
允许和停止均收到真实卡片回调；桌面接力使用实际 AGY 输入框和 Send 按钮，
原生历史与 Lark 消息回读一致。当前由 systemd 托管网关，AGY 桌面独立运行。
这些结论仅适用于本次指定的 Linux / AGY 2.13.0 / SDK 1.4.0 实例。

## 本轮实现

| 模块 | 行为 |
|---|---|
| Lark 边界 | 锁定 SDK 1.4.0，保留原始事件头，校验 app/tenant/user/chat；只接受本人私聊 |
| 线程与退出 | 回调交给主循环；独立 WebSocket 循环；串行化 SDK 两条并发清理路径，避免互相取消清理任务 |
| 本地身份 | 仓库外 0600 凭据文件、5 分钟配对码、本机确认 owner；未配对不能执行 |
| 输入和路由 | 持久化去重、固定 binding、引用卡片路由、普通排队、显式 steer |
| 控制 | stop 先暂停队列、确认空闲后仍暂停；审批绑定原请求指纹与消息，到期记录拒绝意图 |
| 恢复 | 中断的提交变 UNKNOWN；核对 tag 或原生状态，不自动重发 |
| 投递 | 稳定卡片版本、分块、一次性按钮；429 有限退避，未知新建不重发 |
| 诊断 | PID 启动身份与心跳；实时运行状态和按 owner/实例保存的历史验收分开报告 |
| 运维 | 本机 systemd 非 root 网关服务、异常重启、受限写目录；尚无通用安装器 |

## 真实验收

| 项目 | 证据和结果 |
|---|---|
| 手机普通输入 → AGY → Lark | 两条真实输入的正文不变、原生 tag 各出现一次；最终卡片已发送并回读；用户确认可用 |
| 桌面显示 Lark 输入 | 打开用户的原生会话，桌面可见原消息及 `Lark · Unilark` 来源 |
| 桌面输入 → Lark | 专用测试会话通过实际输入框发送；输入与回答两张卡片从 Lark 回读；无网关 tag、无新增网关输入操作、无回灌 |
| Lark 允许审批 | 真实 `card.action.trigger` 回调，原请求获准，指定测试空文件创建成功 |
| Lark 停止 | 真实按钮回调，运行中的 sleep 被 `context canceled` 中断；确认原生空闲，本地队列保持暂停 |
| 待审批时重启 | 原生绑定、当前选择和 14 张卡片保持；重启后的真实回调处理原审批请求 |
| 服务交接 | 16 张既有卡片、输入、会话、选择完全保留；真实 SDK 正常退出无 pending-task / never-awaited 警告；新进程心跳健康 |
| 空闲网关异常退出 | 验明进程后 SIGKILL，systemd 自动重启并恢复连接；18 张卡片的 ID/版本及输入、绑定、选择不变 |

私有证据位于仓库外 `spike/evidence/m1-real-lark-acceptance.json` 与
`m1-desktop-ui-relay.json`、`m1-service-recovery.json`；服务快照位于 `~/.unilark/run/`。
