## 本机运行

网关、AGY 和虚拟桌面由三个独立 systemd 服务监督，以原用户运行。网关用稳定的 `current` 程序路径；数据库为 schema 2。
凭据留在 `~/.unilark/lark.env`（0600），不在仓库或安装包中。网关日志已轮转，辅助宿主继续使用私有 Unix socket；旧 9800 控制端口保持关闭。
运行命令及状态路径见 [OPERATIONS.md](OPERATIONS.md)，通用安装/升级说明见 [install.md](install.md)。
