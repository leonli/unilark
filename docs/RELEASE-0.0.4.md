# Unilark 0.0.4 · 会话分块与富文本

2026-09-13，实验版。

- 会话独立分块，当前会话蓝底，其他会话灰底。标题、状态、项目、队列、按钮分层，操作区增加分割线。
- 待处理、暂停、状态待确认显示橙色标签；保留中文文字，不仅依靠颜色。
- AGY 回复使用 JSON 2.0 Markdown，支持标题、列表、引用、代码块、链接、表格。长代码闭合续卡，长表格保留表头。
- 完整的独立 Mermaid 代码块本机生成 PNG，再上传当前应用，可点击预览。未完成、失败和超限时保留源码。
- 保留原会话引用、消息 ID、按钮和审批语义。当前同时执行上限仍为 1。

使用 `/list` 查看新版列表，或让 Agent 输出 Markdown 和 Mermaid 图表。当前主机无需重新配对或补充权限。
客户端需要 Lark 7.20+。安装步骤及浏览器依赖见 [安装指南](install.md)，手机操作见手册 U24。

本地测试覆盖 Markdown 分块、600 行代码和表格、流式图表、脱敏、缓存/失败、原卡更新与引用、分块按钮路由。
真实 Chromium 验证中文流程图、时序图、非法源码和外部图片请求阻断，PNG 已查看。
真实 Lark API 接受新版列表、命令、表单、Markdown 和图像卡；旧消息从 JSON 1.0 更新为 2.0 成功。
真实 AGY → Hub 的回复投影和账本重建去重通过；该测试投递端为本地 Recorder。

Lark 实际不允许在 JSON 1.0 column 中放 action 按钮组，最终实现改成嵌套列中的按钮。
JSON 2.0 消息 GET 返回兼容占位内容，无法回读 Markdown 正文或原图 key；无图片最小卡也已复核。
因此 API 测试不能作为手机视觉或正文回读证据。已有 acceptance CLI 的正文匹配门禁保留，不能为新版卡新记通过。
已有验收记录不被覆盖；真实手机明暗主题、表格和图片预览仍需客户端反馈。

## 运行边界

正文在解析前完整脱敏。图表在本机渲染，浏览器禁止网络及图内安全配置覆盖，设定大小和时间上限。
缓存限定当前应用和进程；同图避免重复上传，失败冷却 30 秒。详情见安装指南。
独立围栏内的 Mermaid 会转图片；嵌套在列表或引用内的图表保留为 Markdown 代码。

随包包含 Mermaid 11.17.2、MIT 许可证和来源校验；npm tarball SHA-512 与脚本 SHA-256 已核验。
运行依赖增加 markdown-it-py 4.2.0、Playwright 1.62.0。Chromium 需要单独安装，不在离线包内。
数据库保持 schema 2，使用原有备份、候选验证和健康门禁升级。可兼容回退前版 0.0.3，保留业务数据。
